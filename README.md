# 🚗 ByCar

A empresa atua na área de venda e negociação de carros por meio de um site.

O sistema principal da empresa é o site **bycar.com**, onde os clientes podem visualizar carros disponíveis para compra.

No site, cada carro possui informações importantes, como modelo, marca, ano e preço.

Além da venda direta, a ByCar também fica à disposição para negociar valores com os clientes interessados.

## 📖 Descrição do Sistema

O sistema da **ByCar** foi criado para facilitar a busca e a negociação de carros.

Por meio do site, o usuário consegue consultar os veículos disponíveis sem precisar ir até uma loja física.

O sistema ajuda o cliente a comparar modelos, preços e informações básicas dos carros.

A plataforma também permite que a empresa organize melhor os veículos disponíveis para venda.

Com isso, a ByCar oferece uma forma mais simples e prática de aproximar clientes e vendedores.

## Área de Atuação

A ByCar atua no setor de **venda e revenda de veículos**.

O objetivo da empresa é oferecer uma plataforma simples para pessoas que desejam comprar carros de forma mais rápida e organizada, alem de preços que cabem em seu bolso!

## Funcionalidades do Sistema

- Listagem de carros disponíveis para venda
- Visualização de informações dos veículos
- Consulta de preços
- Página com detalhes de cada carro
- Possibilidade de negociação de valores
- Contato com a empresa pelo site
- Organização dos veículos por marca, modelo e preço

## Como Executar o Projeto

Para executar o projeto localmente, siga os passos abaixo:
## CASO ESTEJA USANDO WINDOWS
```bash
# Clone o repositório em sua pasta
git clone https://github.com/usuario/bycar.git

# Entre na pasta do projeto
cd bycar

# Crie um ambiente virtual para instalar as dependencias
python -m venv venv

# Ative o ambiente virtual no Windows
venv\Scripts\activate

# Instale as dependências
pip install -r requirements.txt

# Execute as migrações do banco de dados
python manage.py migrate

# Inicie o servidor local
python manage.py runserver
```

## CASO ESTEJA USANDO LINUX/MAC

```bash
# Clone o repositório em sua pasta
git clone https://github.com/usuario/bycar.git

# Entre na pasta do projeto
cd bycar

# Crie um ambiente virtual para instalar as dependências
python3 -m venv venv

# Ative o ambiente virtual no Mac/Linux
source venv/bin/activate

# Instale as dependências
pip install -r requirements.txt

# Execute as migrações do banco de dados
python manage.py migrate

# Inicie o servidor local
python manage.py runserver

```

Depois disso, acesse o projeto no navegador:

```bash
http://127.0.0.1:8000/
```
ou

```bash
http://localhost:8000/
```

## Explicação das Pastas

- **src/**: pasta principal onde ficam os arquivos do sistema.
- **pages/**: pasta usada para organizar as páginas do site.
- **static/**: pasta onde ficam arquivos estáticos como CSS, JavaScript e imagens.
- **templates/**: pasta onde ficam os arquivos HTML do projeto.
- **docs/**: pasta usada para guardar documentos do projeto.
- **tests/**: pasta usada para testes do sistema.
